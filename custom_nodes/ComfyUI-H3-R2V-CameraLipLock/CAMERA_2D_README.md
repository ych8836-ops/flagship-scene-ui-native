# 카메라 2D 재구도 — 실제 동작 범위

이 워크플로우는 기존 AI 재생성 방식과 별개입니다. 원본 영상을 자르고 이동·확대하는 **2D 재구도**이며, 3D 카메라나 새 시점 생성 기능이 아닙니다.

## 사용

1. 새 노드 설치 후 ComfyUI를 재시작하고 브라우저를 Ctrl+F5로 새로고침합니다.
2. `H3_Camera_2D_Reframe_AllInOne.json`을 불러옵니다. 기존 SourceEdit 워크플로우를 다시 실행하면 종전 AI 재생성 방식으로 동작합니다.
3. 올인원 화면에서 원본 영상을 업로드합니다. 새 영상은 길이에 맞춰 3구간으로 나뉩니다.
4. 각 SEGMENT에서 시작/끝 시간, 샷 크기, 이동 방향, 속도, 강도, 크롭 위치를 설정합니다.
5. 영상 생성을 누릅니다. 결과는 `노드 보기`의 SaveVideo에서 확인합니다. 노드 보기에서 올인원으로 돌아갈 수 있습니다.

## 지원과 제한

- WIDE: 현재 원본 범위. 원본 밖의 배경을 만들지 않습니다.
- MEDIUM/MCU/CLOSE/ECU: 인물 인식이 아닌 고정 크롭 배율입니다. `크롭 위치`로 구도를 맞추세요.
- ZOOM IN/OUT (2D): 실제 원본 크롭 영역을 시간에 따라 확대/축소합니다. 원근감이 변하는 실제 돌리가 아닙니다.
- PAN L/R, TILT UP/DN: 화면 이동입니다. 이동 공간을 확보하기 위해 약간 확대합니다.
- MOTION STRENGTH: 실제 이동 거리/줌 배율에 반영됩니다. 0이면 이동하지 않습니다.
- 속도: 같은 구간 길이에서 이동량/줌 변화량을 조절합니다.
- 크롭 위치: 남는 가로/세로 공간에서 0~1 위치입니다. 인물 자동 추적은 없습니다.
- 오빗/하이앵글/로우앵글/OTS/자동 트래킹은 미지원이며 비활성화합니다. 구형 JSON에 해당 값이 남아 있으면 오류로 알리고 멋대로 다른 동작으로 바꾸지 않습니다.
- 샷 경계에서 구도가 달라질 수 있습니다. 이 버전에는 구간 사이 자동 연속 카메라 경로 보간이 없습니다.
- 24fps 기준 프레임 순서/개수를 유지합니다. 원본이 다른 fps이면 기존 로더가 24fps로 변환합니다.
- 원본 구간 오디오를 동일 순서로 연결합니다. 생성형 음성, 오디오 VAE, H3 샘플러는 사용하지 않습니다. 최종 저장 코덱에 따라 오디오 재인코딩은 발생할 수 있습니다.
- 종횡비를 변경하면 크롭됩니다. 확대는 새 디테일을 복원하지 않으며, 잘린 영역은 보이지 않습니다.
- GPU에서 프레임 단위로 처리하지만 원본 로더는 영상을 RAM에 읽습니다. 매우 긴 고해상도 영상은 메모리 사용량이 큽니다.

## 확인한 결과

사용자 원본 243프레임 / 24fps / 10.125초를 3구간으로 처리했습니다. 동일 시점 비교 이미지로 줌/팬/고정 크롭을 확인했습니다. 단독 통합 테스트는 약 12.4초였으며, ComfyUI 전체 워크플로우 시간은 아닙니다. 원본 오디오를 스트림 복사한 테스트 MP4는 디코딩한 PCM SHA256이 원본과 일치했습니다.

기존 AI 편집 모델, LoRA, 샘플링 설정, 워크플로우는 변경하지 않았습니다. 추가 모델/패키지 설치는 없습니다.

**기존 요청의 모든 3D 시점 변경까지 완성한 것은 아닙니다.** 오빗이나 측면 시점은 별도의 새 시점 생성 접근과 동일성/입모양 검증이 필요합니다.
