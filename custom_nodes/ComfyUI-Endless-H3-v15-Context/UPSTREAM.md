# Upstream

Source: https://github.com/NikoDemon80/ComfyUI-H3-Motion-Context
Upstream version: 0.6.2, downloaded 2026-09-30.
Upstream nodes.py/layout_contract.py are NOT distributed in this pack. The user installs pinned upstream files into ComfyUI/flagship_dependencies/motion_context with the external-dependency installer. The upstream license is downloaded alongside them.
The registration wrapper gives the four core nodes distinct IDs so the
existing locally modified older Motion Context pack can remain installed.
The Flagship registration wrapper is covered by the project license. No additional API routes or global model
patches are installed by this wrapper.
